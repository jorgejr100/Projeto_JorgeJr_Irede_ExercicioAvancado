# Apresentando o Projeto

Este projeto foi desenvolvido utilizando a Unity como forma de aplicar os conhecimentos aprendidos durante as aulas da disciplina.

O ambiente criado representa elementos relacionados aos gostos pessoais do casal, contendo plantas decorativas representando os gostos da minha esposa e naves futurísticas representando os meus gostos pessoais.

O cenário foi montado utilizando paredes com texturas, objetos posicionados em totens e iluminação básica para compor o ambiente virtual. Também foram adicionadas colisões em objetos específicos e interação com os elementos da cena utilizando scripts em C#.

Além disso, o projeto possui interação funcional, permitindo que o usuário interaja com objetos do ambiente e reproduza sons ao ativar determinados elementos do cenário.

---

# Contexto e Objetivos

O objetivo do projeto foi desenvolver um ambiente virtual simples dentro do conceito de Metaverso, explorando interação, ambientação e manipulação de objetos em um espaço 3D.

O projeto representa um ambiente de entretenimento e personalização virtual, demonstrando como espaços digitais podem ser utilizados para representar preferências, identidade e interação do usuário dentro de mundos virtuais.

Também foi utilizado como forma prática de aprendizado sobre:
- manipulação de objetos 3D
- colisões
- scripts em C#
- interação no Unity
- uso de áudio em ambientes virtuais

---

# Processo de Criação e Dificuldades

O desenvolvimento do projeto foi realizado utilizando objetos 3D, aplicação de texturas, configuração de colisões e implementação de scripts em C# dentro da Unity.

Durante o desenvolvimento, algumas dificuldades encontradas foram:
- configuração correta dos Box Colliders
- posicionamento dos objetos no cenário
- configuração do Audio Source
- ativação correta dos sons apenas durante interação
- ícone do audio estava em locais diferentes, deu trabalho pra conseguir colocar no lugar certo
- personagem não anda no meu PC< fica travado, acredito que seja que meu PC não aguenta rodar o Unity

Também houve dificuldades relacionadas à organização dos componentes dentro da Unity, principalmente na associação entre objetos, colisões e reprodução de áudio.

Esses problemas foram resolvidos através de testes práticos, ajustes nos componentes do Unity e revisão das configurações dos objetos presentes na cena.
